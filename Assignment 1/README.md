# 📁 Assignment 1 – Java Basics

This folder is part of the **Java Lab Assignments** repository and contains beginner-friendly Java programs focused on building strong fundamentals in Java programming.

All programs in this folder demonstrate the use of **basic syntax, loops, conditional statements, methods, and user input handling**.

---

# 🧮 Programs Included

## 1️⃣ ArithmeticOperations.java
A Java program that performs basic arithmetic operations on two numbers entered by the user.

### 🔹 Operations Performed
- Addition  
- Subtraction  
- Multiplication  
- Division  
- Modulus  

### 🔹 Concepts Used
- Methods  
- Scanner (user input)  
- Arithmetic operators  
- Class and main method  

---

## 2️⃣ Calculator.java
A menu-driven calculator that allows the user to perform multiple arithmetic operations until they choose to exit.

### 🔹 Features
- Interactive menu  
- Continuous execution using loop  
- Uses switch-case for operation selection  
- Exit option to stop program  

### 🔹 Concepts Used
- Switch case  
- Loops (do-while)  
- Static methods  
- User input handling  

---

## 3️⃣ DivisibilityTest.java
Checks numbers from **1 to 50** and prints whether each number is divisible by 2, 3, or 5.

### 🔹 Concepts Used
- While loop  
- If conditions  
- Modulus operator (%)  
- Logical checking  

---

## 4️⃣ DivisibilityTest2.java
Finds numbers from **1 to 100** that are divisible by **2, 3, and 5 simultaneously**.

### 🔹 Concepts Used
- Loops  
- Logical AND operator (&&)  
- Conditional statements  
- Number filtering logic  

---

# ▶️ How to Run the Programs

### Step 1: Compile
```bash
javac FileName.java
```

### Step 2: Run
```bash
java FileName
```

### Example
```bash
javac Calculator.java
java Calculator
```
