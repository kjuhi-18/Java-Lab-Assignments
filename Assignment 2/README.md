# 📁 Assignment 2 – Java OOP Concepts

This folder is part of the **Java Lab Assignments** repository and focuses on **Object-Oriented Programming (OOP)** concepts in Java.

The programs in this assignment demonstrate how to create classes, objects, constructors, and interact between multiple Java files.

---

# 🚗 Programs Included

## 1️⃣ Vehicle.java
This file defines a **Vehicle class** with properties and behaviors of a vehicle.

### 🔹 Features
- Defines attributes of a vehicle (like name, type, price, etc.)
- Uses constructors to initialize object values
- Demonstrates encapsulation using class structure
- Contains methods to display vehicle details

### 🔹 Concepts Used
- Classes and Objects  
- Constructors  
- Instance variables  
- Methods  
- Object initialization  

---

## 2️⃣ MainForVehicle.java
This file contains the **main method** to run the program and test the Vehicle class.

### 🔹 Features
- Creates objects of Vehicle class  
- Calls methods from another class  
- Displays vehicle information  
- Demonstrates interaction between multiple Java files  

### 🔹 Concepts Used
- Object creation  
- Method calling  
- Class interaction  
- Main method execution  

---

# ▶️ How to Run the Program

Since this program uses multiple Java files, compile both files together.

### Step 1: Compile
```bash
javac Vehicle.java MainForVehicle.java
```

### Step 2: Run
```bash
java MainForVehicle
```
